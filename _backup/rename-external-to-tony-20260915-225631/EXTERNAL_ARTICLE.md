# ENDOSCOPE: внешняя статья о похожем устройстве

Этот файл отдельно фиксирует сведения из внешней статьи. Эти данные не смешивать с тем, что реально получено на нашем устройстве.

## Источник

Nathan Henrie, reverse engineering похожего Wi-Fi эндоскопа:

```text
https://n8henrie.com/2019/02/reverse-engineering-my-wifi-endoscope-part-1/
https://n8henrie.com/2019/02/reverse-engineering-my-wifi-endoscope-part-2/
```

## Как использовали статью

Статья использовалась как ориентир для проверки нашего устройства: какие интерфейсы искать, какие порты проверить, какую скорость UART попробовать, чего ожидать от похожей платы.

## Данные из статьи

Из статьи были взяты только ориентиры:

- похожий адрес устройства `192.168.10.123`;
- наличие Telnet на `23/tcp`;
- наличие сервиса на `7060/tcp`;
- похожий MoLink banner;
- похожая SPI flash Winbond W25Q32;
- UART `57600`;
- пример чужих данных входа из статьи.

## Правило использования

Данные из статьи не считаются результатом нашего устройства, пока не подтверждены нашими фото, UART-логами или сетевыми проверками.

Если признак подтверждён локально, он должен быть описан в `DEVICE.md` со ссылкой на наши логи или файлы проекта.

Если признак есть только в статье, он остаётся здесь.

Чужие данные входа из статьи на нашем устройстве не подошли и не используются как актуальные данные доступа.
