# Project layout

- README.md - main project notes.
- images\ - board photos.
- logs\ - UART captures and command outputs.
- hashcat\ - hashcat input, results and BAT scripts.
- scripts\ - connection helper BAT files.
- docs\ - helper notes and rewrite task.
- dumps\ - firmware or flash dumps, if present.
- tools\ - downloaded helper tools.
- _backup\ - safety backups before reorganization or README rewrite.
